# Smartup marketing website audit

Reviewed 11 September 2026. Scope: brand continuity, marketing hierarchy, content integrity, accessibility basics, responsive layout, media behaviour and Railway readiness.

## Outcome

No blocking implementation issue remains in the reviewed scope. The page preserves the approved purple, cream, Rubik and original owl identity. Its story now starts with a video cover and student success, then video testimonials, sample written testimonials, press, programmes, teaching, people and centres. App downloads are visible in the top bar, hero and dedicated app section. LMS integration remains separate.

## Findings addressed

| Finding | Change | Evidence |
| --- | --- | --- |
| Student proof and app links were not prominent | Added attributed results, equal-height video stories, quotes, media and three app-link placements | Desktop and mobile visual review; source destinations checked |
| Results and testimonials needed source discipline | Original result posters are linked; examination/cohort labels qualify each statistic; every sample quote is marked | Drive sources below; user expressly authorised placeholder content |
| Portrait and landscape media could become visually inconsistent | Shared frame heights, contained media and mobile scroll snap | 360px desktop, 320px tablet, 340px mobile frames measured in browser |
| Embeds could burden initial loading or play simultaneously | Click-to-load YouTube players, one active embed, close/focus restoration, offscreen pause and direct fallback links | Actual landscape and portrait playback; pointer and keyboard close checks |
| Font files were unnecessarily large | Converted five local Rubik weights to WOFF2 | Combined font size reduced from about 860KB to 280KB |
| Mobile navigation depended on JavaScript | Added a visible no-JS navigation layout and direct enquiry fallback | Static source review; normal menu and Escape checked in browser |
| Railway server lacked media-serving behaviour | Added streamed responses, video MIME types, HEAD and single byte-range support | Six server tests pass |
| Sharing metadata lacked imagery | Added an absolute social preview image | Final canonical/domain update remains a launch task |
| Previous owl scroll code no longer targeted visible art | Connected small, bounded motion to the displayed hero owl | Source inspection; mobile/reduced-motion guards |

## Remaining content and launch decisions

- Written quotes are design placeholders authorised by the user, not verified testimonials. Replace them and their attributions with client-approved material before removing sample labels.
- Current videos are YouTube selections for preview. Confirm the final clips, captions and transcripts. No unverified English quotations were extracted from the client's Malayalam videos.
- Confirm legal copy, current admissions/batch details, and missing centre contacts/maps with the client. Existing phone fallbacks remain usable.
- Assign the final Railway/domain URL before adding canonical metadata and changing the social image origin. Railway configuration is included; no Railway account deployment was performed.

## Verification limits

Browser review covered 1440px, 820px, 390px and 320px viewports, visible content, media playback, navigation, class selection and centre fallbacks. Static checks cover assets, anchors, duplicate IDs, alt attributes, motion guards and design rules. This is a practical implementation audit, not a full WCAG certification, exhaustive device test or measured Core Web Vitals report. See `qa.md` for checks performed.
